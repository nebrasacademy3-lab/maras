# إصلاحات مشغل التطبيق — مراس العلم

هذه النسخة جاهزة للبناء عبر EAS ومربوطة مسبقًا بخادم:
`https://marase.up.railway.app`

## ما تم إصلاحه

- تشغيل الفيديو داخل التطبيق نفسه وعدم الاعتماد على فتح رابط خارجي.
- تمرير Bearer Session Token إلى `expo-video` في Android/iOS مع Signed Stream URL كطبقة أمان إضافية.
- `contentFit="contain"` لعرض الفيديو كاملًا بدون قص أو تقريب، مهما كانت أبعاده الأصلية.
- استخدام `textureView` على Android لتقليل مشاكل الـSurface/الشاشة السوداء أثناء التنقل.
- تصميم مشغل قريب من مشغل الويب: تشغيل/إيقاف، ±10 ثوانٍ، شريط تقدم، الوقت، الصوت والكتم، السرعة، الإعدادات، الترجمة عند توفرها، وملء الشاشة.
- إعداد الجودة يعرض `تلقائي / الأصلية` لأن التخزين الحالي يحتوي نسخة فيديو واحدة ولا توجد Transcoding Renditions منفصلة بعد.
- اكتشاف أخطاء `expo-video` الفعلية وإظهار زر إعادة المحاولة داخل المشغل.
- عند الخروج يتم إيقاف الفيديو وتحرير مصدره حتى لا تبقى شاشة فارغة/سوداء معلقة.
- زر الرجوع العلوي وزر الرجوع الفعلي في Android يرجعان إلى نفس صفحة المادة أو غرفة التعلم التي جاء منها الطالب.
- عند الانتقال للدرس السابق/التالي يستخدم نفس شاشة المشغل بدون تكديس شاشات إضافية.

## البناء

```powershell
npm ci
npx eas-cli@latest project:info
npx eas-cli@latest build --platform android --profile preview
```

`preview` ينتج APK قابلًا للتثبيت مباشرة.

## تحقق

شغّل:

```powershell
node VERIFY_VIDEO_FIXES.mjs
```

والنتيجة المتوقعة:
`video fixes: 10/10 checks passed`
