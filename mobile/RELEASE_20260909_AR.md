# تحديث تطبيق مراس — 9 سبتمبر 2026

## التغييرات

- إصلاح انهيار iOS عند مغادرة الدرس: يُحفظ التقدم من لقطة JavaScript تحدّثها أحداث الفيديو، دون قراءة الكائن الأصلي بعد تحريره. تُحفظ اللقطة عند الانتقال إلى الخلفية والمغادرة، ولا يكتب المصدر غير المحمّل تقدمًا صفريًا فوق المحفوظ.
- تصحيح تمييز HLS عن الفيديو الأصلي، وإلغاء متابعة تحميل المصدر بعد مغادرة الشاشة.
- توحيد محاذاة العربية في النصوص والحقول، بما فيها النصوص التي تبدأ برمز مادة إنجليزي. البريد والأرقام التقنية تبقى مقروءة، وحقل التحقق يحافظ على محاذاته في المنتصف.
- إعادة تصميم التحقق من البريد والاستعادة، وتحديث تغيير كلمة المرور مع إظهار/إخفاء النص والتحقق من شروط كلمة المرور وتطابق التأكيد. أضيفت ترجمة إنجليزية للنصوص الجديدة.
- إعادة تصميم «موادي»: إحصاءات فعلية، متابعة التعلم، تصفية المكتبة حسب التقدم، بطاقات للهاتف واللوحي، وحالة اتصال منفصلة عن المكتبة الفارغة.
- ضبط شريط التبويبات حسب عرض الجهاز والمساحات الآمنة، وتحسين وضوح الحقول وحالات التركيز والانشغال.
- تخفيف حركة الدخول والظهور عند التمرير، واحترام تقليل الحركة. يبقى المحتوى مقروءًا حتى إن تأخر قياس موضعه.
- عدم تحميل مكتبة إشعارات النظام في Expo Go والويب؛ تستمر إشعارات الحساب داخل التطبيق. تُحمّل إمكانات push في التطبيق الأصلي المناسب فقط.
- توحيد روابط المساعد والإشعارات، مع فصل الأجزاء # عن الاستعلامات، ودعم روابط الجامعات، ورفض المسارات الملتبسة أو الفواصل المشفرة أو التنقل بالنقاط.
- حماية اعتماد الجلسة في طلبات API والرفع والتنزيل والفيديو من إرساله إلى نطاق مختلف، وتنظيف مستمع إلغاء الطلب، ورفض بدء رفع مُلغى مسبقًا.
- منع استجابة تحديث حساب متأخرة من إعادة المستخدم بعد تسجيل الخروج، ومسح بيانات الحساب المخبأة عند انتهاء الجلسة أو تبديل الحساب.

## التحقق

- TypeScript: دون أخطاء.
- ESLint: دون أخطاء أو تحذيرات؛ أُعيد فحص الملفات المعدلة بعد الفحص العام.
- الاختبارات: 43 اختبارًا ناجحًا، تشمل محاكاة تحرير مشغل الفيديو قبل حفظ التقدم، ومحاذاة النصوص والرمز، وبيئات الإشعارات، وحماية الطلبات والتنزيلات، وتسجيل الخروج، وروابط الجامعات والروابط التي تحتوي #.
- تدقيق اعتمادات التشغيل: لا ثغرات معروفة في نتيجة npm audit --omit=dev بتاريخ الفحص. هذه نتيجة قاعدة بيانات التدقيق وليست ضمانًا لغياب كل الثغرات.
- حزم JavaScript/Hermes: جُمّعت للويب وiOS وAndroid. هذا تجميع للكود وليس إصدار ملفات APK أو IPA موقّعة.
- لم تتغير ملفات mobile/package.json أو mobile/package-lock.json ضمن هذه التعديلات؛ التغييرات السابقة فيهما محفوظة.

لإعادة التحقق من داخل mobile:

```text
npm run typecheck
npm run lint
npm test
npm audit --omit=dev
npx expo export --platform all --max-workers 2 --output-dir .expo/qa-all
```

حدّثت أدوات VERIFY_VIDEO_FIXES.mjs وVERIFY_RTL_AND_EXPO.mjs لتشغيل اختبارات السلوك الحالية بدل أنماط قديمة في الشيفرة.

## تحقق الأجهزة قبل النشر

لم تتوفر في هذه البيئة أجهزة iPhone/Android فعلية أو محاكيات، ولم تُنفّذ معاملات حقيقية أو إرسال بريد/push لحسابات إنتاج. يُراجع الإصدار التطويري على الجهاز كما يلي:

1. درس مجاني ودرس مفعل: تشغيل، تقديم وتأخير، تدوير، تكبير، فتح الإعدادات، ثم الرجوع والإغلاق أثناء التحميل. إعادة فتح الدرس للتحقق من استعادة التقدم.
2. الخلفية والقفل والعودة، مع حماية التقاط الشاشة بحسب إمكانات النظام.
3. العربية والإنجليزية والوضعان الفاتح والداكن، وتكبير خط النظام، ولوحة المفاتيح على هاتف صغير وجهاز لوحي.
4. التحقق من البريد، اللصق والإكمال التلقائي لرمز عربي/إنجليزي، إعادة الإرسال، استعادة كلمة المرور وتغييرها.
5. الدخول والخروج وانتهاء الجلسة وتبديل الحساب؛ التأكد من عدم ظهور بيانات الحساب السابق.
6. تفعيل push في development build/نسخة موزعة، والضغط على إشعار لدرس أو جامعة أو طلب. لا يُعتمد Expo Go لاختبار إمكانات push الكاملة.
7. اختبار الأدوار والرفع والتنزيل والشراء في بيئة الاختبار المعتمدة للخدمات الخارجية قبل الإطلاق.
