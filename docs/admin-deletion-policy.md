# سياسة الحذف النهائي الإداري

هذه السياسة تخص لوحة الإدارة فقط. لا يقبل الخادم اسم جدول من العميل؛ كل نوع كيان يمر عبر قائمة بيضاء ثابتة وإجراء محدد.

## قواعد عامة

| الكيان | القرار | التوابع والتنظيف | القيود |
|---|---|---|---|
| مؤسسة | حذف نهائي مشروط | روابط المؤسسة، تخصصات غير المستخدمة، المواد التابعة وأبناؤها | يمنع إذا وجدت مادة مرتبطة بتاريخ مالي أو طلبات/وصول فعّال، وتُبقى سجلات التدقيق |
| تخصص | حذف نهائي مشروط | روابط المؤسسة، المواد التابعة وأبناؤها | يمنع إذا كانت له مواد مرتبطة ماليًا أو إذا كان الرابط مشتركًا مع مؤسسة أخرى دون إزالة آمنة |
| مادة | حذف نهائي مشروط | فيديوهات وملفاتها، الدروس، الوحدات، التقدم، الملاحظات، المفضلة، السلة، المراجعات، الوصول الإداري غير المالي | يمنع عند وجود طلبات مدفوعة، فواتير، أحداث دفع، أو وصول فعّال لا يمكن سحبه بأمان |
| وحدة | حذف نهائي | الدروس، الفيديوهات وملفاتها، التقدم، الملاحظات | يمنع إن كانت تابعة لمادة غير موجودة؛ لا يلمس الطلبات أو المالية |
| درس | حذف نهائي | الفيديو والملف، التقدم، الملاحظات | لا حذف ذاتي أو طلابي |
| فيديو | حذف صف وملف | كائن التخزين المرتبط بـ objectKey | إداري فقط؛ لا يكسر درسًا آخر، ويُحدّث الكاش |
| مستخدم طالب/مشرف | حذف نهائي مشروط | الجلسات، reset/OTP المرتبط إن أمكن، الأجهزة، السلة، المفضلة، الملاحظات، التقدم، الإشعارات، التكليفات، ملفات الطلبات والدعم وتذاكر الدعم | يمنع إذا وُجد طلب مدفوع أو فاتورة أو حدث دفع؛ يمنع حذف الحساب الإداري الحالي أو آخر مدير |
| طلب مادة | حذف نهائي | ملفات الطلب وكائناتها | إداري فقط مع تدقيق؛ لا يحذف أوامر الشراء |
| تذكرة دعم | حذف نهائي | الردود وملفات الرد وكائناتها | إداري/مدير فقط؛ سجل التدقيق يبقى |
| كوبون | حذف صف | لا توابع | لا يعيد كتابة الفواتير أو الطلبات السابقة |
| إشعار | حذف صف | لا توابع | لا يحذف سجل التدقيق |
| مراجعة | حذف صف | لا توابع | لا يحذف المادة أو المستخدم |
| تكليف مشرف | حذف صف | لا توابع | لا يحذف المشرف |
| إعداد عام | لا حذف افتراضي | — | التعديل أو استعادة الافتراضيات أكثر أمانًا من حذف شامل |
| طلب/فاتورة/حدث دفع | ممنوع | — | سجل مالي وidempotency لا يُحذفان؛ استخدم إخفاء/سحب وصول مستقبلًا |

## التحقق الإلزامي

يجب أن يكون الطلب من مدير مصادق عليه أو مسار machine-admin قائمًا، مع فحص same-origin في المسارات غير الآلية، وتحديد معدل للحذف، وتأكيد نصي يساوي `حذف` للعمليات المدمرة. يجب منع حذف الحساب الإداري الحالي وآخر مدير نشط. تنفذ إزالة الصفوف في معاملة واحدة، ثم تحذف كائنات التخزين best-effort مع تسجيل إخفاقات التنظيف في نتيجة العملية والتدقيق دون كشف أسرار.

## ترتيب الحذف

يكون الترتيب دائمًا children-first: ملفات الدعم/الطلب ثم الردود/التذاكر، ملفات الفيديو ثم صفوف الفيديو ثم الدروس ثم الوحدات ثم المادة، روابط المؤسسة ثم المواد ثم التخصصات غير المستخدمة ثم المؤسسة، وتوابع المستخدم غير المالية ثم المستخدم. لا يعتمد التنفيذ على `ON DELETE CASCADE` غير الموثق.
