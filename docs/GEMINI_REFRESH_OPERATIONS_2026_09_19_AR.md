# مراس — تجديد إثبات Gemini ومؤشرات التشغيل

19 سبتمبر 2026. استكمال الدفعة المتوقفة فوق `8fb52df36f5e5be83cadd92aa450122482f0d333` في فرع `integration/v7-on-main-20260919` وPR #7. استُعيدت الشجرة الجزئية المحفوظة، وأُكملت ملفات القبول وواجهتا الويب والتطبيق. هذا المستند لا يعلن نشر الإنتاج أو قبول جميع متطلبات v7.

## التنفيذ

يبقى إثبات المشروع محدودًا بـ15 دقيقة؛ يرفض مسار التوليد الإثبات المنتهي أو المجهول. يضيف الترحيل المحافظ `0041_gemini_project_refresh` بصمة الخطة وسجل جدولة اختياريًا. لا يستنتج مجانية المشروع من تسمية المفتاح، ولا يخزن رمز OAuth أو قيمة API key في سجل التجديد. الحارس `AI_PAID_PRICING_UNVERIFIED` ما زال يمنع التوليد المدفوع؛ التجديد ليس تنفيذًا لتسعير الاحتياط أو تصريحًا بتفعيله.

تسجيل التجديد عملية صريحة بعد إثبات الخطة نفسها ومراجعتها. لا تكفي إضافة مفتاح أو إجراء تحقق لمرة واحدة لإنشاء جدولة. يستحوذ عامل واحد على المشروع باستخدام `FOR UPDATE SKIP LOCKED` وإيجار 45 ثانية بساعة PostgreSQL. النجاح يعيد الجدولة بعد 240–270 ثانية؛ الفشل بعد 30–315 ثانية بحسب تتابع الإخفاقات. الحد التشغيلي 32 مشروعًا مجدولًا، لا 32 مفتاحًا ولا ادعاءً بقياس سعة إنتاجية. يحتفظ المشروع بعدادات الاستهلاك والتبريد عند التجديد.

يحمل كل إيجار معرفًا وإصدار خطة. الإيقاف أو تسجيل خطة جديدة أو استعادة إيجار منتهٍ يمنع العامل القديم من نشر إثبات أو تعديل موعد العامل اللاحق. فشل التجديد يبطل الدليل الأقدم، لكنه لا يبطل دليلًا أحدث اعتمده مشغل مستقل. المفتاح الذي عطله المسؤول لا يعاد تنشيطه آليًا.

إجمالي قراءة Google محدود بـ12 ثانية. ينهي حارس العامل العملية بخروج غير صفري إذا تجاوزت دورة كاملة 40 ثانية، ويشمل ذلك انتظار قاعدة البيانات. عامل التجديد، عند تفعيله، جزء مطلوب من مشرف العمليات؛ فشله ليس خدمة ميتة مخفية خلف خادم ويب سليم ظاهريًا. فحص مصدر الهوية عند الإقلاع محدود بـ15 ثانية.

## الهوية والإعداد

`GEMINI_PROJECT_REFRESH_ENABLED=false` افتراضيًا. قبل تفعيله في staging: نسخة احتياطية، تطبيق الترحيل، مشروع مستقل، حدود نماذج مراجعة، مفاتيح نشطة، وهوية قراءة معتمدة من الشركة. التطبيق لا ينشئ حساب خدمة، ولا يوسع IAM، ولا يربط حساب فوترة، ولا يغيّر إعدادات Google.

تحتاج قراءة المشروع والفوترة `resourcemanager.projects.get`، وتحتاج مطابقة سر المفتاح `apikeys.keys.getKeyString` على الموارد المعنية. توثق Google نطاق `cloud-platform.read-only` لقراءة المفاتيح، و`cloud-billing.readonly` لقراءة الفوترة. لا تمنح Owner/Editor أو صلاحيات تغيير الفوترة لمجرد تشغيل القارئ. مراجع Google الرسمية:

- https://docs.cloud.google.com/api-keys/docs/reference/rest/v2/projects.locations.keys/getKeyString
- https://docs.cloud.google.com/billing/docs/reference/rest/v1/projects/getBillingInfo
- https://docs.cloud.google.com/billing/docs/reference/rest/v1/ProjectBillingInfo

يتولى وكيل هوية موثوق خارج العامل إصدار الرمز قصير العمر وتجديده واستبدال الملف ذريًا. يشير `GEMINI_CONTROL_PLANE_TOKEN_FILE` إلى مسار Linux محلي مطلق وحقيقي، مثل `/run/maras-identity/google-readonly.json`. الملف JSON بصلاحيات `0600`، مملوك للمستخدم المشغّل أو root، داخل أدلة موثوقة غير قابلة للكتابة من مستخدم آخر. يرفض القارئ الروابط الرمزية والصلبة والأنابيب والملفات الكبيرة والترميز غير الصالح. Windows غير مدعوم لهذا القارئ لأن فحوص POSIX لا تثبت حماية ملفه هناك.

شكل توضيحي فقط — ليس اعتمادًا صالحًا:

```json
{"accessToken":"SHORT_LIVED_TOKEN_FROM_TRUSTED_AGENT","expiresAt":"YYYY-MM-DDTHH:mm:ss.sssZ"}
```

وقت الانتهاء UTC حقيقي، والمدة المتبقية من 30 ثانية إلى 70 دقيقة. هذه فحوص للملف الذي يكتبه الوكيل الموثوق، وليست تحققًا مشفرًا من الرمز؛ Google هو جهة التحقق الفعلية. يقرأ العامل الملف في كل محاولة، فلا يحتاج دوران الرمز إلى إعادة تشغيل. لا يوضع الرمز في سطر الأوامر أو Git أو سجلات التشغيل. هذه الحدود لا تحمي من root مخترق أو وكيل هوية غير موثوق.

## أوامر التشغيل

تُمرّر `DATABASE_URL` ومصادر الهوية عبر إدارة الأسرار. ملف الخطة غير سري ولكنه يجب أن يكون داخل دليل موثوق. بنيته في `GEMINI_PROJECT_ADMISSION_2026_09_19_AR.md`؛ لا تتضمن الخطة قيم المفاتيح.

```sh
# إثبات الخطة ثم تسجيل تجديدها؛ لا يبدأ عاملًا ولا يطلب توليدًا.
node --import ./scripts/ai-worker-runtime.mjs \
  --require ./scripts/tsx-runtime-bootstrap.cjs --import tsx \
  scripts/gemini-projects.ts enable-refresh --read-only-google /run/maras-identity/project-plan.json

# أعداد إجمالية بلا اتصالات Google.
node --import ./scripts/ai-worker-runtime.mjs \
  --require ./scripts/tsx-runtime-bootstrap.cjs --import tsx \
  scripts/gemini-projects.ts status

# إيقاف الخطة وإبطال إثباتها الحالي وحجب كتابة العامل القديم.
node --import ./scripts/ai-worker-runtime.mjs \
  --require ./scripts/tsx-runtime-bootstrap.cjs --import tsx \
  scripts/gemini-projects.ts disable-refresh PROJECT_NUMBER
```

بعد قبول staging فقط، يفعّل المشغل `GEMINI_PROJECT_REFRESH_ENABLED=true` مع مسار الرمز ويستخدم مشرف التطبيق المعتاد. الأمر `verify --read-only-google` القديم تحقق لمرة واحدة باستخدام اعتماد المشغل، ولا ينشئ جدولة. إيقاف العملية وحده لا يبطل إثباتًا فورًا؛ استخدم `disable-refresh` للإلغاء الفوري، وإلا ينتهي الدليل في مدته الطبيعية.

في الرجوع عن إصدار التطبيق يمكن تعطيل العامل والإبقاء على الترحيل الإضافي دون حذف بيانات. استعادة نسخة قديمة من قاعدة البيانات يجب أن تتم معزولة وفق دليل التعافي؛ لا تُشغّل عمال التوليد عليها قبل مراجعة حداثة الاستهلاك والإثبات والخطط. النسخة القديمة لا تثبت استهلاكًا وقع بعد أخذها.

## الواجهات والصلاحيات

تعرض لوحة التشغيل ثمانية أعداد فقط: المشاريع المسجلة، والإثباتات الصالحة والمنتهية والقريبة من الانتهاء، والتجديد المجدول والجاري والمتعثر والمتأخر. لا تعرض رقم المشروع أو بصمة المفتاح أو خطة الهوية. API محمي بمنح التشغيل والنطاق العام القائمة، ورده `cache-control: no-store`.

عقد `operations-contract.ts` متطابق حرفيًا في الخادم والعميل الأصلي ويُفحص في CI. تعرض الواجهتان أعداد Gemini والتنظيف. تبويب التحليلات والدعم والامتثال وأزرار إرسال التنبيهات لا تظهر ولا تستدعي بياناتها دون المنحة المستقلة المناسبة. منح العرض لا تسمح بتعديل الامتثال. يبقى الخادم المرجع الأمني، لا حراسة الواجهة وحدها.

مفاتيح كاش بيانات تشغيل التطبيق مرتبطة بمعرف المستخدم والمنح وحالة المالك، وتُمرّر إشارة إلغاء الطلب. تبديل الحساب يمنع إعادة زر قديم تحت هوية جديدة. تبديل سياق منح الويب يعيد تركيب الشاشة ويمحو بياناتها ومسوداتها. الواجهة لا تجعل فشل جلب المؤشرات نجاحًا صفريًا. تمنع الويب نقرات التنفيذ المتكررة أثناء الطلب، وتتجاهل نتيجة قراءة أقدم وصلت بعد قراءة أحدث، وتعرض فشل النقل بدل تسريبه كرفض وعد غير معالج.

## الأدلة وحدود القبول

اجتاز `scripts/qa-gemini-refresh.ts` محليًا **15 سيناريو** على PostgreSQL حقيقي معزول ونقل Google اصطناعي محصور بالعناوين الثابتة. يشمل التسجيل الصريح، 12 عاملًا متنافسًا، دوران الرمز، رفض 403، انتهاء الهوية، الإيقاف أثناء الطلب، موت عملية طفل واستعادة إيجارها، منع العامل القديم، تغيير الخطة، حفظ دليل أحدث، فساد الخطة، الحظر اليدوي، الإلغاء، مؤشرات بلا أسرار، وتشغيل مدخل العامل الفعلي.

اجتاز `tests/gemini-refresh-files.test.mjs` و`tests/operations-access.test.mjs` **23 اختبارًا** محليًا، منها صلاحيات نظام الملفات الفعلي وحجب اعتمادات الإنتاج عند مدخل CI، وتنفيذ مكونات الويب والتطبيق تحت خطافات اختبار. اختبارات المكونات ليست أجهزة Android/iOS فعلية.

أُضيف اختبار API ولوحة التشغيل إلى مسار المتصفح الحقيقي: Chromium وFirefox وWebKit، بمظهرين وأربعة عروض، مع حجب المشرف غير المخول. نتيجة CI النهائية مرتبطة بالالتزام الذي شُغّل؛ وجود الاختبار أو نجاح التزام سابق ليس دليلًا على نجاح الالتزام الجديد. تُرفع التقارير والصور في قائمة أدلة محددة، لا ملفات الهوية أو قاعدة الاختبار أو الجلسات الاصطناعية.

متطلبات v7 الأصلية المحفوظة في مكتبة المشروع تتضمن **192 معيار قبول مطلوبًا**، وليس 192 نجاحًا محسوبًا من اختبارات الوحدة. هذه الدفعة تدعم خصوصًا إثبات المشروع وحماية الأسرار والواجهات، ولا تغلق وحدها جميع KP أو ST أو LF أو ID أو MFA. ما زال قبول هوية الشركة الفعلية، جودة العينات العلمية، الحدود الحقيقية للمزود، الاحتياط المدفوع وتقدير تكلفته، التوقيع والمتاجر والأجهزة الفعلية بوابات منفصلة. لم تُفعّل الفوترة أو EMAIL_CHANGE أو نشر الإنتاج في هذه الدفعة.
