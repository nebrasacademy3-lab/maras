## ما ينفذه الكود

الترحيل `0040_gemini_project_admission` يضيف سجل المشاريع وبصمات مفاتيحها وحدود النماذج وحجوزات التنفيذ. لا يرحّل أوصاف المفاتيح القديمة إلى إثباتات: الجداول تبدأ فارغة، والتوليد يبقى محجوبًا حتى تحقق المشغل.

أمر التحقق يجري طلبات GET فقط إلى ثلاثة نطاقات ثابتة: Cloud Resource Manager لإثبات رقم المشروع واسمه وحالته ACTIVE؛ API Keys لإثبات تطابق مورد المفتاح مع بصمته؛ Cloud Billing لقراءة ارتباط الفوترة في نهاية التحقق. لا يتبع تحويلات HTTP، ولا يضع المفاتيح في الاستعلام، ولا يحفظ المفتاح العائد أو رمز OAuth في سجل الإثبات أو المخرجات. المهلة الإجمالية 12 ثانية وحجم كل استجابة محدود. السجل يحفظ بصمة الأدلة ووقت جمعها ومراجعة عشوائية؛ هذه بصمة تدقيق محلية وليست توقيع Google مستقلًا.

الإثبات صالح 15 دقيقة كحد أقصى محسوبة من بدء جمع الأدلة، مع رفض اختلاف ساعة الخادم/قاعدة البيانات بأكثر من 30 ثانية. فشل التحديث يلغي الإثبات الأقدم ولا يلغي تحديثًا أحدث. المشروع المرتبط بحساب فوترة مغلق أو معطل لا يصنف مجانيًا. المشروع المرتبط بفوترة نشطة مصنف مدفوع ويظل محجوبًا عن التوليد.

الحجز يستخدم قفل PostgreSQL على رقم المشروع وحدودًا لكل مشروع ونموذج. مفاتيح المشروع الواحد والخوادم المختلفة تتشارك RPM وTPM وRPD والتزامن. يوجد حد عام أقدم للمزود أيضًا؛ هذا التغيير لا يلغيه. التدوير لا يعامل مفاتيح المشروع نفسه كمشاريع مستقلة أو كمضاعفات للحصة.

يُحجز سقف رموز الإدخال كاملًا قبل `countTokens`، ويظل السقف محجوزًا حتى انقضاء النافذة؛ لا يعاد الفرق تفاؤليًا. العد يرى نسخة ثابتة مطابقة لطلب التوليد، بما فيها تعليمات النظام ومخطط الإجابة. بعد العد يعاد فحص الإثبات والمفتاح والمراجعة والحدود قبل الإرسال. عدد المخرجات إلزامي ومحدود، والعد غير الصحيح أو المتجاوز للسقف يمنع التوليد. خصائص توليد جديدة غير معتمدة لا تمر تلقائيًا إلى المزود.

تاريخ الحصة اليومية محسوب في PostgreSQL وفق `America/Los_Angeles`. حجز التزامن 150 ثانية، والنافذة المحافظة قبل معرفة النتيجة 210 ثوانٍ، وتبقى دقيقة إضافية بعد النجاح. المهلة الخارجية لا تتجاوز 120 ثانية. عند انقطاع الاتصال أو غموض النتيجة لا يحرر الحجز تفاؤليًا. انتهاء الحجز لا يعني إثبات توقف المعالجة داخل Google؛ هذه حدود إرسال محلية وليست تحكمًا في عمليات المزود الداخلية. أخطاء 429 تمدد تهدئة مشتركة؛ تحديث الإثبات أو نجاح طلب قديم لا يمسحها. أخطاء الانشغال المحلية تستخدم آلية الانتظار القائمة في عامل الملفات بدل الفشل النهائي الفوري.

## تشغيل التحقق في بيئة معزولة أولًا

يجب تطبيق الترحيل في staging مع نسخة احتياطية وخطة رجوع، ثم إعداد مشروع Google مخصص ومفاتيح نشطة محفوظة في مراس. لا تستخدم مشاريع يتشاركها عملاء أو تطبيقات خارج هذا الحجز. حدود المثال أدناه توضيحية وليست حصة Google أو توصية تشغيل معتمدة.

ملف خطة غير سري، مع استبدال القيم بالمشروع والمورد والبصمة الكاملة الصحيحة:

```json
{
  "projectNumber": "123456789012",
  "projectId": "your-google-project",
  "keys": [
    {
      "resource": "projects/123456789012/locations/global/keys/your-key-resource-id",
      "fingerprint": "REPLACE_WITH_THE_64_LOWERCASE_HEX_SHA256_FINGERPRINT"
    }
  ],
  "models": [
    {
      "model": "gemini-2.5-flash",
      "rpm": 2,
      "tpm": 20000,
      "rpd": 20,
      "concurrent": 1,
      "inputTokens": 10000,
      "outputTokens": 1024
    }
  ]
}
```

البصمة هي `SHA256("meras-ai-key:v1:" + apiKey)`، ومتاحة كاملة للمشغل في `ai_api_keys.fingerprint`. اختصار الاثني عشر حرفًا الظاهر في الإدارة غير كافٍ. لا تضع القيمة السرية للمفتاح في ملف الخطة. معرّف مورد المفتاح يؤخذ من Google، وليس وصفه الحر داخل مراس. كل مفاتيح الخطة يجب أن تكون نشطة ومحفوظة أو معرّفة صراحة في بيئة الخادم.

جهّز `DATABASE_URL` و`GEMINI_CONTROL_PLANE_ACCESS_TOKEN` في بيئة المشغل الآمنة، دون تسجيلهما أو تمريرهما في معاملات سطر الأوامر. التوكن قصير العمر ومن حساب مصرح له بقراءة المشروع والفوترة و`apikeys.keys.getKeyString`. الأمر لا يطلب أي صلاحية ربط فوترة أو تعديل حساب، ولا يحمل ملف `.env` ضمنيًا:

```sh
node --import ./scripts/ai-worker-runtime.mjs \
  --require ./scripts/tsx-runtime-bootstrap.cjs --import tsx \
  scripts/gemini-projects.ts verify --read-only-google /secure/non-secret-project-plan.json
```

ينتهي الأمر بحالة مشروع غير سرية أو خطأ منقح. لا ينشئ جدولة تلقائية ولا ينشر خدمة. يجب تجهيز مصدر توكن قصير العمر وتجديد الإثبات من مشغل موثوق قبل انتهاء 15 دقيقة في خطة التشغيل؛ غياب التجديد يعطل التوليد عمدًا. لا توفر لوحة الإدارة مفتاحًا يسمح بادعاء «تم التحقق» يدويًا.

جميع مسارات التوليد المدفوع محجوبة، حتى لو كانت سياسة SAR القديمة محفوظة على أنها enabled. تفعيلها من الإدارة يرفض برمز `AI_PAID_PRICING_UNVERIFIED`. سقوف التقدير الثابت القديمة لا تشكل تسعيرًا مثبتًا لأقصى مدخلات ومخرجات وتفكير أو أدوات. لا يوجد متغير بيئة جديد يتجاوز هذه الحماية.

إثبات ارتباط الفوترة لقطة زمنية، وليس ضمانًا لاستحالة تغيير الفوترة بعد القراءة أو أثناء الطلب. يلزم مشروع مخصص، تقييد صلاحيات تعديل الفوترة، ومراقبة/تجديد معتمد. كما أن الحدود المحلية لا تشمل استخدام التطبيق خارج هذا النظام، ولا تكتشف تلقائيًا مجموعات الحصص التي قد تشترك فيها أسماء نماذج مختلفة. يجب اعتماد النماذج والمجموعات الفعلية وحدودها من AI Studio قبل تشغيل حي. الترحيل لا يمنح حصة Google ولا يثبت توفر نموذج بعينه للحساب.

تبقى اختبارات Google الحية وتجديد الهوية التشغيلي، وتسعير المدفوع، وقبول الملفات العلمية الكبيرة، واستكمال الرفع القابل للاستئناف للملفات الدراسية والعميل الأصلي، واختبار S3 الحي، والأجهزة الفعلية والتكاملات الحية ضمن بوابات الإطلاق المفتوحة. لا تتغير حالة PR #7 كمسودة ولا يُدّعى اكتمال حالات 192 غير المتاحة.
