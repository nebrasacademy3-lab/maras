## ما تغيّر

### مراقبة العمليات

- يبدأ الويب وعاملا الفيديو والذكاء بأوامر ثابتة دون shell. خروج أي عملية مطلوبة، حتى برمز صفر غير متوقع، ينهي المجموعة برمز فشل بدل إبقاء واجهة تبدو سليمة مع عامل متوقف.
- تُرسل إشارات الإيقاف إلى مجموعات العمليات، بما يشمل أبناء العامل مثل FFmpeg. مهلة الإيقاف الافتراضية 25 ثانية، وحد إعدادها 1–60 ثانية؛ بعد المهلة يستخدم الإيقاف القسري. يثبّت Docker أداة tini لإعادة حصد العمليات اليتيمة.
- تُتحقق أعلام العمال والمنفذ والمهلة قبل ترحيلات البدء. استعلام انتظار قاعدة البيانات محدود الزمن، ولا يسجل تفاصيل الاتصال الخام.
- هذه مراقبة حياة العمليات، لا إثبات تقدم عامل عالق أو سلامة المزود. يجب ضبط مهلة إنهاء الحاوية بما يناسب مهلة الإيقاف واختبار الاستئناف الفعلي للمهام قبل نشر واسع.

### فحص الجاهزية والتخزين

- فحص قاعدة البيانات والتخزين موحد للطلبات المتزامنة داخل العملية، بمهلة 3.5 ثانية وذاكرة قصيرة لمدة ثانيتين. لا يفتح كل طلب HTTP اتصال فحص جديدًا.
- عند انتهاء المهلة تبقى مهمة الفحص المحجوزة حتى يستقر العمل الأصلي؛ لا تتراكم عمليات معلقة إذا تجاهلت جهة الإرسال الإلغاء. اتصال PostgreSQL الملغى يُتلف، ولا تعاد وصلة ما زال استعلامها يعمل إلى المسبح.
- مسار `/api/health` كان موجودًا بالفعل في `railway.json`؛ لم ندّع إضافته من الصفر. نجاح فحص النشر لا يعوض المراقبة المستمرة أو اختبار الحمل.

### Gemini فقط

- أزيل استدعاء OpenAI من المساعد العام وربط بسجل Gemini والمنظم المشترك وإعداد خدمة `chat`. لا يستخدم المساعد العام الاحتياط المدفوع حتى عند تفعيله لأدوات أخرى.
- يحتفظ المساعد بالدليل البرمجي للمنصة عند التعطل، دون توليد من مزود آخر. لا تتغير سياسة إنفاق المستخدم أو نماذجه المنشورة تلقائيًا.
- تنقل بيانات السياق المسترجع إلى رسالة بيانات محدودة الحجم، لا تدمج في تعليمات النظام. تبقى تصفية روابط الإدارة والروابط الخارجية والتحقق من الرد في الخادم.
