# استئناف رفع مستندات الدراسة — 20 سبتمبر 2026

النطاق: استئناف الرفع الفعلي عبر خادم المنصة للويب وعميل Expo، لا Amazon S3 Multipart الأصلي. يحترم حد الحساب الحالي حتى سقف 50MiB؛ لا يرفع خطة الطالب أو يصرف من Gemini. هذه الدفعة لا تحقق تلقائيًا استئناف **توليد** أجزاء المستند أو الدقة العلمية.

## التنفيذ

- جلسة PostgreSQL لمدة 24 ساعة، وSHA-256 وطول مثبت لكل جزء 4MiB. يُعاد فحص البصمة أثناء التجميع؛ لا يعتمد ملف جزئي أو يسمح باستبداله بعد الاعتماد.
- معرّف منع تكرار محفوظ قبل طلب البدء؛ فقد رد البدء أو الجزء أو الاعتماد يُسوّى عند إعادة اختيار الملف نفسه. مفتاح الحفظ مرتبط بمعرف الحساب وبصمة جميع الأجزاء والاسم والنوع والوجهة، لا بالاسم والحجم وحدهما. لا تُحفظ بايتات الملفات أو مسارات الهاتف أو رموز المصادقة.
- آلية انتقال واحدة مشتركة حرفيًا بين الويب والتطبيق. يقرأ الهاتف بأجزاء عبر FileHandle، ويغلق المقبض دائمًا. يتوقف العميل عند تغيّر الحساب/الجلسة أو اختفاء الملف، ولا يعرض توليدًا لم يبدأ. زر إيقاف مؤقت يحفظ إمكان الاستئناف دون وعد بوصول 100% قبل اعتماد الخادم.
- ملكية الحساب والمحادثة تُراجع عند كل عملية وفي معاملة الاعتماد. ترويسة حساب صريحة تمنع طلبًا قديمًا من الانتقال إلى حساب جديد. الجلسة المكتملة تشير إلى الملف نفسه ولا يعاد فتحها إذا حذف الملف.
- حصص الملفات والبايتات مشتركة مع مسار multipart القديم. الحجوزات المفتوحة أو المحجوبة والتنظيف غير المكتمل تحتسب؛ انتهاء TTL وحده لا يتيح إعادة استخدام المساحة. جلستان للحساب، 16 على مستوى رفع مستندات الدراسة، وتجميعان متزامنان.
- فحص الماسح لم يُخفّف: غياب الماسح يترك الملف pending_scan لا ready. الأجزاء الخام لا تتاح للطالب عبر مسار تنزيل عام. تجميع الأجزاء والتنظيف ذو مهلة.
- صندوق التنظيف الدائم يسجل حذف البادئة الخاصة بالجلسة داخل معاملة الاعتماد/الانتهاء. معرف المالك يبقى كشاهد للتنظيف بعد حذف الحساب، ولا تسقط الجلسة عبر FK cascade؛ تغير موقع التخزين يحجب التنظيف للمراجعة.

## دليل الاختبارات

`tests/study-upload-client.test.mjs`: عشر حالات سلوكية؛ تطابق العميلين، التحقق من البيان، الانقطاع، فقد الردود الثلاثة، تغيير المحتوى بنفس الاسم والحجم، تغيير الملف أثناء الإرسال، الإلغاء والحدود وإيصالات غير صالحة.

`scripts/qa-study-upload.ts`: ثماني مجموعات على PostgreSQL وملفات محلية فعلية، منها عملية فرعية تخرج فور اعتماد الجزء الأول، تجميعان متزامنان ينتجان ملفًا واحدًا، مقارنة كل بايت، بصمة فاسدة عند التجميع، عزل مالك آخر، حجز التخزين والإلغاء، الحساب الموقوف، الموقع المتغير، وحذف ملف مكتمل. مسار النقل الخارجي محجوب داخل الاختبار. رُبط الاختبار بـCI ويحفظ تقريره؛ قبول الالتزام المرفوع مرهون بنجاح تشغيله نفسه لا نجاح محلي أقدم.

محليًا على مصدر هذه الدفعة قبل إضافة زر الإيقاف البصري: بناء الويب و814 اختبارًا دون إخفاق/تخطٍّ. فحص الأنواع للويب والتطبيق نجح. ليست هذه نتائج جهاز Android/iPhone فعلي ولا قبول S3 حيًا.

## بوابات مستقلة

قراءة/تقسيم/توليد المستند الكبير، جودة الترجمة والنطق والاختبار، S3/CORS الحي، أجهزة فعلية والتوقيع والنشر، مراجعة ملكيات الإنتاج القديمة ونسخ مخزن الإنتاج واستعادته، وميزانيات Gemini المدفوعة لا تصبح مكتملة بهذه الدفعة. لا دمج إلى main أو تفعيل EMAIL_CHANGE أو paid fallback.
