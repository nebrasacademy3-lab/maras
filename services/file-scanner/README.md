# خدمة فحص المرفقات الاختيارية

هذا جسر HTTP موثّق برمز مشترك إلى ClamAV، وليس بديلًا شكليًا لمضاد الفيروسات. يبقى الملف معلّقًا عند انقطاع الماسح أو غموض النتيجة. لا تفتح منفذ clamd رقم 3310 للإنترنت.

شغّل `docker compose up -d --build` من هذا المجلد بعد وضع `MALWARE_SCAN_TOKEN` عشوائي لا يقل عن 32 حرفًا في بيئة التشغيل. الماسح يستخدم `freshclam` من صورة ClamAV لتحديث التواقيع؛ يجب مراقبة نجاح تنزيلها وجهوزية clamd. ثبّت صورة ClamAV بدليل digest بعد التحقق منها في بيئة النشر بدل الاعتماد الطويل على stable.

في المنصة اضبط `MALWARE_SCAN_URL` على عنوان `/scan` القابل للوصول من خدمة الويب، و`MALWARE_SCAN_TOKEN` بالقيمة نفسها. المثال المحلي يربط HTTP على loopback فقط. في الخدمات المنفصلة استعمل شبكة خاصة، أو HTTPS مع شهادة موثوقة. لا تستبدل SSL بالقبول العام للشهادات.

`GET /health` يثبت أن الجسر يعمل فقط، ولا يعلن جاهزية محرك ClamAV. اختبر رفع ملف نصي سليم وملف EICAR الرسمي المخصص لاختبار مضادات الفيروسات في بيئة اختبار؛ النتيجة السليمة يجب أن تكون clean، وEICAR يجب عزله. لا تستخدم مستندات الطلاب الحساسة للاختبار. شغّل مسار إعادة الفحص الإداري دوريًا `/api/admin/files/scan` بالاعتماديات الحالية للمهام المصرح بها؛ أعِد الطلب حين `hasMore=true`.

مرجع البروتوكول: https://docs.clamav.net/manual/Usage/ClamdProtocol.html

حدود التسليم: اختُبر محلل النتائج والحدود وبروتوكول النقل مع خادم اختبار. لم تُنزّل صورة ClamAV أو تواقيعها في بيئة إعداد الملف، ولم يُختبر إرسال ملف إنتاج.
