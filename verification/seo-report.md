# تقرير SEO واكتشاف المنصة — 12 سبتمبر 2026

اجتازت القوالب العامة الثمانية عشر قياس Lighthouse 13.4.1 بنتيجة **100/100 في قسم SEO**، دون تدقيق آلي فاشل أو تحذير في الجولة النهائية. القياس على نسخة إنتاج محلية بقاعدة بيانات تجريبية، وليس على الموقع المنشور.

## التحقق الفعلي

| النطاق | النتيجة |
| --- | --- |

| جميع روابط خريطة الموقع | جرى طلب **112 رابطًا من أصل 112**؛ كلها 200 وبالرابط الأساسي والبيانات الوصفية الصحيحة، دون صفحات حسابات أو إدارة |
| سياسات الزحف | التحقق من Googlebot وBingbot وOAI-SearchBot وPerplexityBot وGPTBot؛ الوصول العام مسموح وواجهات API مستثناة كما في السياسة السابقة |

| لوحة إدارة SEO | تعديل العنوان والوصف من الواجهة، تحقق من ظهور التعديل فعليًا في HTML العام، ثم استعادة النص الأصلي |
| العرض المتجاوب | الأدوات وملف الطالب 360 وقائمة المادة عند عرض 390 بكسل؛ عرض الصفحة 390 دون تمرير أفقي خارج الصفحة |

القوالب المقاسة: الرئيسية، المواد، الجامعات، صفحة مادة، صفحة جامعة، صفحة تخصص، الباقات، صفحة باقة، الأدوات، عن المنصة، الأسئلة الشائعة، طريقة العمل، التواصل، الشروط، الخصوصية، الاسترداد، حقوق المحتوى، وإمكانية الوصول. أسماء المواد والجامعات التجريبية ليست بيانات تشغيل.

## إصلاح ظهر أثناء القياس

ظهرت نتيجة 91 في أربع صفحات لأن الوصف بقي في جسم الصفحة بدل رأسها، وأكد المتصفح استمرار ذلك بعد انتظار عشر ثوانٍ في بعض الزيارات. استُخدم خيار Next.js الموثق `htmlLimitedBots: /.*/` لحسم البيانات الوصفية قبل إخراج HTML لجميع الزوار. بعد إعادة البناء، ثبت وجود الأوصاف في الرأس عند تحميل الصفحات الأربع، واجتازت القوالب الثمانية عشر القياس.

هذا الخيار يؤخر بدء بث الصفحة حتى اكتمال البيانات الوصفية. يجب قياس زمن الاستجابة على الاستضافة وقاعدة البيانات الفعلية؛ الأزمنة التشخيصية المحلية ليست مقارنة سرعة قبل التطوير وبعده.

## إعداد القياس وحدوده

أدخل برنامج الحماية المثبت على جهاز الاختبار طلبات متكررة إلى صفحات المتصفح، فأصدرت جولات Lighthouse الافتراضية تحذير انتظار الشبكة. بقي برنامج الحماية يعمل دون تعطيل أو حجب. استخدمت الجولة النهائية قسم SEO فقط مع:

- `networkQuietThresholdMs: 0`
- `pauseAfterLoadMs: 1000`
- `cpuQuietThresholdMs: 1000`
- إعداد Lighthouse المحمول الافتراضي، وثلاث عمليات مستقلة.

حُفظت الجولات الافتراضية وتحذيراتها، وتقارير ما قبل إصلاح الرأس وما بعده. لم تُقَس نقاط الأداء أو تحسين السرعة، ولا تمثل نقطة SEO فحص أمن شاملًا أو ضمان ترتيب في البحث.

اختبارات الواجهة استعملت Playwright CLI مع Headless Chrome 152؛ استخدم Lighthouse متصفح Microsoft Edge بمحرك Chromium. لم يُختبر Firefox أو WebKit/Safari أو هاتف حقيقي ضمن هذا التقرير. توثيق الشاشات بعرض الهاتف لا يُعد اختبار تطبيق أصلي. تحتوي دورات الاختبار بيانات جاهزية فقط، فلا تثبت اللقطات تشغيل الفيديو.
