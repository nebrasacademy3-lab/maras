# مراس العلم

منصة تعليم جامعي سعودية عربية بالكامل، مبنية بـ React 19 وNext.js/Vinext، مع واجهة RTL متجاوبة ووضع فاتح وليلي، كتالوج جامعات وكليات، صفحات مواد، لوحة طالب، لوحة مشرف، لوحة إدارة، دفع Tap، قاعدة بيانات D1، وتدفق فيديو خاص عبر R2.

## النسخة المنشورة

`https://meras-alelm.glossy-sun-8084.chatgpt.site`

## أبرز ما يتضمنه المشروع

- الصفحة الرئيسية، البحث السريع، الفلاتر، الجامعات، التخصصات والمواد.
- كتالوج يضم 85 جامعة وكلية وجهة تقنية سعودية وفق أدلة وزارة التعليم ومجلس شؤون الجامعات، مع شعارات رسمية متى أتاحها المصدر وبديل من النطاق الرسمي، ومعالجة بصرية للوضعين.
- تخصصات مرتبطة بكل جهة بدل القائمة العشوائية؛ تُزامن الجامعات المتاحة في «ادرس في السعودية» مع المصدر الرسمي وقت التشغيل، ويظهر رابط المصدر ونسخة احتياطية منظمة عند تعذر الاتصال.
- دليل مواد داخل كل تخصص، وبحث وتصنيف حسب المجال والدرجة العلمية، مع انتقال مباشر لطلب شرح مادة غير متوفرة.
- صفحة تفصيل لكل جامعة ومادة، درس تجريبي، تقييمات، أسعار ومدة الوصول.
- تسجيل ودخول فعليان بكلمات مرور PBKDF2 وجلسات HttpOnly آمنة وملف إلزامي يشمل الجوال والجامعة والتخصص.
- جولة بداية لأول دخول تشرح الاستكشاف والمشغل والدفع وطلب مادة مع رفع السلايدات.
- لوحة طالب مرتبطة بقاعدة البيانات: الصلاحيات الحقيقية، التقدم، الطلبات، الفواتير، الإشعارات، تذاكر الدعم وردودها، الحساب، وتوصيات الجامعة والتخصص مع حرية شراء مواد الجهات الأخرى.
- لوحة مشرف محمية بالدور: طلبات الطلاب ومرفقاتها وحالاتها، بناء الوحدات والدروس، رفع الفيديو، وجاهزية المحتوى ضمن نطاق الجامعة/التخصص المسند فقط.
- لوحة إدارة حية شاملة: المستخدمون والأدوار، الجامعات وشعاراتها، التخصصات وربطها، المواد والأسعار، الوحدات والدروس والفيديو، الطلبات، الصلاحيات، الدعم والردود، التقييمات، الإشعارات، الكوبونات، روابط التواصل، وجاهزية الخدمات وسجل التدقيق.
- طلب مادة مرتبط بالطالب ويقبل 5 مرفقات خاصة، يُسند لمشرف ويولّد إشعارات حالة للطرفين.
- Tap Checkout من الخادم وWebhook يعيد التحقق من العملية قبل منح صلاحية المادة.
- مساعد مراس ذكي ثابت بعلامة M الشفافة دون الكلمات، بخلفية بيضاء في الوضع الفاتح وداكنة في الوضع الليلي. يستخدم Gemini عند ضبط المفتاح مع سياق الكتالوج والحساب والحالات الحية وروابط التنفيذ، ويعود إلى قاعدة معرفة محلية آمنة عند تعذر المزود.
- مشغل مراس: تشغيل وإيقاف، تقديم/رجوع 10 ثوان، صوت، سرعات، ملء الشاشة، اختصارات، حفظ تقدم، منع قائمة السياق والتنزيل من الواجهة، وعلامة مائية متحركة باسم الطالب.
- بث خاص عبر R2 بروابط HMAC موقعة تنتهي بعد 30 دقيقة ومرتبطة بجلسة الحساب، مع إعادة التحقق من صلاحية المادة عند كل طلب بث.
- SEO، Open Graph، خريطة موقع، robots، manifest، 404، وسياسات قانونية ووصول.
- حماية متعددة الطبقات: CSP وHSTS، تحقق Origin، rate limiting، RBAC، جلسات قابلة للإبطال، استعادة كلمة مرور مؤقتة، وتدقيق كامل في Webhook الدفع.

## تطبيق Android وiOS

يتضمن التسليم تطبيق Expo/React Native أصليًا يتصل بقاعدة الحسابات والكتالوج والصلاحيات نفسها عبر واجهات `/api/mobile/*`. أضيف دعم Bearer sessions مخزنة في SecureStore، تسجيل أجهزة Expo Push، إشعارات تحديث الطلبات والدعم ومنح المواد، المفضلة والملاحظات والفواتير، حذف الحساب، ولوحات أصلية للطالب والمشرف والإدارة.

هجرة `0006_robust_nicolaos.sql` تنشئ جدول `push_devices` وتُطبق تلقائيًا مع بقية الهجرات عند تشغيل Railway. اضبط `EXPO_PUBLIC_API_URL` داخل مشروع التطبيق على نطاق Railway النهائي، ولا تضع مفاتيح Tap أو Gemini أو توقيع الفيديو داخل التطبيق.

## التشغيل محليًا

المتطلبات: Node.js 22.13 أو أحدث.

```bash
npm ci
npm run db:generate
npm run dev
```

لتجربة قاعدة البيانات المحلية وتطبيق الهجرات:

```bash
npx wrangler d1 migrations apply DB --local --config wrangler.railway.jsonc
```

## متغيرات البيئة

انسخ `.env.example` إلى ملف بيئة محلي، ثم أضف القيم المطلوبة. لا ترفع المفاتيح السرية إلى Git.

| المتغير | الغرض |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | الرابط العام المستخدم في SEO أثناء البناء |
| `APP_URL` | الرابط العام لعودة Tap والـ webhook |
| `TAP_SECRET_KEY` | مفتاح Tap السري؛ يبقى في الخادم فقط |
| `TAP_PUBLIC_KEY` | المفتاح العام عند إضافة Tap Elements مستقبلًا |
| `TAP_MERCHANT_ID` | معرّف التاجر إن طلبه إعداد حساب Tap |
| `VIDEO_SIGNING_SECRET` | سر عشوائي 32 حرفًا أو أكثر لتوقيع روابط الفيديو |
| `ADMIN_API_TOKEN` | حماية واجهات القراءة الإدارية |
| `ADMIN_UPLOAD_TOKEN` | حماية رفع ملفات الفيديو الخاصة |
| `TRUST_CHATGPT_AUTH_HEADERS` | اتركه `false` على Railway؛ فعّله فقط خلف بوابة موثوقة تحذف ترويسات المستخدم وتحقن ترويسات ChatGPT بنفسها |
| `RESEND_API_KEY` | إرسال رسائل استعادة كلمة المرور عبر Resend |
| `EMAIL_FROM` | المرسل الموثّق، مثال `مراس العلم <no-reply@domain.sa>` |
| `ASSISTANT_PROVIDER` | اتركه `gemini` لتفعيل المزود الذكي |
| `GEMINI_API_KEY` | مفتاح Gemini للمساعد السياقي؛ عند غيابه يعمل الرد المحلي المحدود |
| `GEMINI_MODEL` | نموذج Gemini المستخدم، والقيمة الافتراضية `gemini-3.7-flash` |

عند غياب `TAP_SECRET_KEY` يوقف الخادم الدفع برسالة واضحة ولا ينشئ طلبًا وهميًا أو مطالبة مالية. عند إضافة المفتاح تعمل الإحالة إلى Tap الحقيقي تلقائيًا.

## إنشاء حساب إدارة أو مشرف

التسجيل العام ينشئ طلابًا فقط، ولا توجد روابط تجريبية تكشف لوحات الموظفين. أنشئ حساب الموظف من الخادم باستخدام `ADMIN_API_TOKEN`:

```bash
curl -X POST https://your-domain.example/api/admin/staff \
  -H "Authorization: Bearer YOUR_ADMIN_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@domain.sa","phone":"0500000000","fullName":"مدير المنصة","password":"Strong!Pass123","role":"admin","universitySlug":"ksu","specialty":"إدارة الأعمال"}'
```

استخدم `role: "supervisor"` للمشرف. عند إنشائه تُسجّل له أيضًا مهمة الجامعة/التخصص لاستخدامها في إسناد طلبات الطلاب والتحقق من صلاحية رفع المحتوى.

## النشر على Railway

المشروع يحتوي `Dockerfile` جاهزًا، وRailway يكتشفه عند رفع المجلد أو ربط المستودع.

1. ارفع المجلد إلى GitHub أو نفّذ `railway up` من داخله.
2. أضف متغيرات البيئة السابقة في إعدادات الخدمة.
3. أضف Volume دائمًا واربطه بالمسار `/data` لحفظ D1 وR2 المحليين بين عمليات إعادة التشغيل. يقرأ سكربت التشغيل `RAILWAY_VOLUME_MOUNT_PATH` تلقائيًا.
4. أنشئ نطاقًا عامًا، واضبط `APP_URL` و`NEXT_PUBLIC_SITE_URL` على رابط HTTPS النهائي، ثم أعد النشر.
5. اضبط فحص الصحة على `/api/health` إن رغبت في zero-downtime checks.

أمر التشغيل الموجود في الصورة:

```bash
bash scripts/start-railway.sh
```

يطبّق السكربت هجرات قاعدة البيانات تلقائيًا، ثم يشغّل حزمة Worker الإنتاجية على `0.0.0.0:$PORT` مع تخزين محلي دائم عند وجود Volume.

## ربط Tap

التدفق المطبق:

1. يحسب الخادم السعر والخصم من بيانات المادة والكوبون الفعليين في قاعدة البيانات؛ لا يثق بالمبلغ الذي يعرضه المتصفح.
2. ينشئ طلبًا بحالة `pending`.
3. ينشئ Charge لدى Tap ويرسل المستخدم إلى `transaction.url`.
4. يستقبل `/api/webhooks/tap` الإشعار، ثم يجلب العملية مرة أخرى من Tap بالمفتاح السري.
5. يمنح `course_access` ويحتسب استخدام الكوبون مرة واحدة فقط عندما تكون الحالة الموثقة `CAPTURED`.

لـ Apple Pay يجب إكمال تفعيل الوسيلة والتحقق من النطاق داخل حساب Tap. روابط Tap الرسمية:

- https://developers.tap.company/reference/create-a-charge
- https://developers.tap.company/docs/webhook
- https://developers.tap.company/docs/apple-pay-web-sdk

## الفيديو المحمي

رفع فيديو خاص:

```bash
curl -X POST https://your-domain.example/api/admin/videos \
  -H "x-admin-upload-token: YOUR_TOKEN" \
  -F "courseSlug=discrete-structures" \
  -F "lessonId=d-1" \
  -F "file=@lesson.mp4"
```

واجهة `/api/video/session` تتحقق من هوية المستخدم وصلاحية المادة، ثم تعيد رابطًا مؤقتًا. مسار البث يدعم Range Requests ويجبر العرض `inline` ولا يكشف مفتاح R2 العام.

مهم: لا يمكن لأي موقع ويب منع تسجيل الشاشة أو استخراج البث بنسبة 100%. المنصة تطبق منع التنزيل من الواجهة، روابطًا قصيرة العمر، وصولًا مرتبطًا بالحساب، علامة مائية، مخزنًا خاصًا، وسجلات. للمحتوى عالي القيمة استخدم HLS مشفرًا وDRM (Widevine/FairPlay/PlayReady) عبر مزود فيديو متخصص بدل ملف MP4 واحد.

## الحسابات والصلاحيات

الحسابات العامة فعلية ومحفوظة في D1. لا يقرأ المتصفح رمز الجلسة، ولا تمنح واجهات الإدارة إلا للدور المخزن في قاعدة البيانات. مسار الدفع يتجاهل أي بيانات مشترٍ يرسلها العميل ويستخدم ملف الطالب الموثق فقط. استعادة كلمة المرور تعمل عبر Resend عند ضبط المفتاح، وتبقى الرسالة عامة حتى لا تكشف وجود البريد. الثقة بترويسات ChatGPT معطلة افتراضيًا لمنع انتحالها على Railway، ولا تُفعّل إلا خلف بوابة موثوقة تحذف ترويسات العميل قبل حقن هوية المستخدم.

## البنية

- `app/`: الصفحات وواجهات API.
- `components/`: نظام الواجهة والمشغل واللوحات.
- `lib/data.ts`: بيانات العرض والجامعات والمواد.
- `db/schema.ts`: مخطط قاعدة البيانات.
- `drizzle/`: هجرات SQL.
- `worker/`: نقطة تشغيل Cloudflare/Vinext.
- `scripts/start-railway.sh`: تشغيل Railway وتطبيق الهجرات.
