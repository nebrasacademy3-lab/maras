# مراس العلم

**مراس العلم** منصة تعليم جامعي عربية تضم تطبيق ويب مبنيًا بـNext.js، وتطبيق Expo/React Native للويب وAndroid وiOS، وخادم PostgreSQL عبر Drizzle. تشترك القنوات في الحسابات والكتالوج والصلاحيات وطلبات المواد والدعم والإعلانات والإشعارات والتقدم الدراسي.

## بنية المشروع

| المجلد | المحتوى |
|---|---|
| `backend/` | واجهة الويب، لوحات الطالب والمشرف والإدارة، واجهات API، المصادقة، PostgreSQL، Tap، الفيديو، الرفع، الإشعارات والمساعد. |
| `mobile/` | تطبيق Expo/React Native للويب وAndroid وiOS، مرتبط بالخادم نفسه ويستخدم جلسة آمنة على الأجهزة و`localStorage` في Expo Web. |
| `backend/drizzle/` | هجرات قاعدة البيانات، بما فيها التزامن الفوري، حالة قراءة الإشعارات لكل مستخدم، وحالة تسليم Push المجدول. |
| `backend/tests/` | اختبارات العقود والأمان والتكامل وتشغيل الإنتاج. |

## الوظائف الجاهزة

تستخدم المنصة علامة مراس الرسمية ذات النجمة في الويب والتطبيق وأيقونات Android وiOS وPWA، مع هوامش آمنة تمنع القص. تدعم الواجهات الاتجاه العربي والوضعين الفاتح والليلي والثيمات وأحجام النص، وتقدم شاشة ترحيب وتهيئة أولى مبسطة، وفلاتر جامعات وتخصصات قابلة للبحث بدل القوائم الطويلة.

يعرض الكتالوج 85 جهة تعليمية و168 تخصصًا فريدًا و3,009 روابط جهة–تخصص عند تشغيل بذور `core`. تستطيع الإدارة مزامنة برامج جامعة محددة من منصة «ادرس في السعودية» الحكومية، مع حفظ المصدر وحالة التحقق والتاريخ، دون إعادة نشر سجل أخفاه المدير يدويًا. يعتمد دليل الجهات على مصادر وزارة التعليم والمنصة الحكومية الرسمية.[1] [2]

يمكن نشر مادة وفتح الاشتراك فيها بعد وجود **درس واحد منشور وجاهز على الأقل**. تظهر بقية الدروس للطالب بصفتها «قريبًا»، وتدخل تلقائيًا ضمن الوصول نفسه عند نشرها. يُحسب تقدم الطالب من الدروس المتاحة فقط، بينما تمنع السلة والدفع أي مادة لا تحتوي درسًا جاهزًا.

يدعم رفع الدعم وطلبات المواد وفيديوهات الإدارة نسبة تقدم وسرعة ووقتًا متبقيًا وإلغاءً ومهلة واضحة. يقبل طلب المادة حتى 100 ملف بإجمالي 100MB، بينما يصل حد فيديو الإدارة إلى 200MB. ضُبط `proxyClientMaxBodySize` على 220MB حتى لا يقطع Next.js جسم الطلب قبل وصوله إلى التحقق الداخلي؛ وهذا هو إعداد Next.js المخصص لهذه الحالة.[3]

تدعم الإعلانات جمهور الزوار أو الطلاب أو الجميع أو مستخدمًا محددًا، مع شريط أو نافذة أو صندوق إشعارات، وجدولة بداية ونهاية، ورابط داخلي آمن. تُحسب حالة القراءة لكل طالب بصورة مستقلة. تفحص خدمة Expo Push رد المزود، وتلغي الرموز غير المسجلة، وتعيد ملخص الأجهزة المستهدفة والمقبولة والمرفوضة. تحتاج النسخ المنشورة إلى `EXPO_PUBLIC_EAS_PROJECT_ID` حقيقي وفق إعداد Expo Push.[4]

يقرأ المساعد الكتالوج والإعدادات والحساب والطلبات والدعم الحية ضمن صلاحية المستخدم. يفهم العربية واللهجات والأخطاء، ويعيد إجابة منظمة وروابط داخلية مصفاة. يقبل `OPENAI_API_URL` سواء كان عنوان `/v1` أو مسار `chat/completions` كاملًا. إذا غاب المفتاح أو تعذر النموذج، يبقى الرد الحتمي المحلي فعالًا.

## تشغيل الخادم محليًا

يتطلب الخادم Node.js 22 أو أحدث وPostgreSQL 14 أو أحدث. انسخ ملف البيئة النموذجي وعدّل القيم السرية قبل التشغيل.

```bash
cd backend
npm ci
cp .env.example .env
npm run db:migrate
npm run dev
```

يفتح الخادم عادة على `http://localhost:3000`. عند غياب قاعدة البيانات أثناء البناء تستخدم الصفحات العامة بيانات عرض مضمنة، بينما يوضح `/api/health` حالة قاعدة البيانات عند التشغيل.

## تشغيل التطبيق

```bash
cd mobile
npm ci
cp .env.example .env
npm start
```

يُستخدم `http://localhost:3000` محليًا فقط. يجب أن تكون `EXPO_PUBLIC_API_URL` قيمة HTTPS الفعلية في بناء الإنتاج. لا تضع مفاتيح Tap أو OpenAI أو أسرار الجلسات داخل تطبيق Expo.

## متغيرات الإنتاج المهمة

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL الذي يقدمه Railway. |
| `SESSION_SECRET` | سر عشوائي مستقل لا يقل عمليًا عن 32 محرفًا. |
| `ADMIN_API_TOKEN` | إدارة آلية وتشغيل توزيع Push المجدول. |
| `ADMIN_UPLOAD_TOKEN` | رفع إداري منفصل عن رمز الإدارة العام. |
| `VIDEO_SIGNING_SECRET` | توقيع جلسات وروابط الفيديو المؤقتة. |
| `APP_URL` و`NEXT_PUBLIC_SITE_URL` | رابط الويب العام HTTPS. |
| `EXPO_WEB_ORIGIN` | أصل Expo Web المنشور إذا كان على نطاق مختلف؛ يجب أن يطابق CORS وCSRF. |
| `OPENAI_API_KEY` | مفتاح المساعد الديناميكي، اختياري. |
| `OPENAI_API_URL` | عنوان أساس مثل `https://api.openai.com/v1` أو مسار الإكمال كاملًا. |
| `ASSISTANT_MODEL` | النموذج؛ القيمة النموذجية `gpt-5-mini`. |
| `TAP_SECRET_KEY` و`TAP_WEBHOOK_SECRET` | الدفع والتحقق من Webhook. |
| `RESEND_API_KEY` و`EMAIL_FROM` | استعادة كلمة المرور عبر البريد. |
| `UPLOAD_DIR` | مجلد التخزين الدائم؛ الافتراضي في Railway هو `/data/uploads`. |

## النشر على Railway

المجلد المقصود للنشر هو `backend`. يحتوي على `Dockerfile` و`railway.json` و`scripts/start-railway.sh`. يطبق سكربت الإقلاع الهجرات، ويجهز بذور الكتالوج، ثم يشغل Next.js على `0.0.0.0:$PORT`. اربط Volume دائمًا بالمسار `/data` حتى لا تضيع الفيديوهات والمرفقات والشعارات عند إعادة النشر.

استخدم `RUN_DB_MIGRATIONS=true` و`AUTO_SEED_CATALOG=true` و`CATALOG_SEED_MODE=core` في النشر العادي. لا يستبدل التمهيد تعديلات الإدارة على السجلات الموجودة. استخدم `full` فقط إذا أردت إنشاء عدد كبير من قوالب المواد وتقبل زمنًا ومساحة أكبر.

لتسليم حملات Push المجدولة، أنشئ خدمة Cron في Railway تستخدم الشيفرة نفسها ومتغيرات `APP_URL` و`ADMIN_API_TOKEN`، وشغّل الأمر التالي كل دقيقة أو خمس دقائق بحسب الدقة المطلوبة:

```bash
./scripts/dispatch-notifications.sh
```

يمكن للمدير أيضًا تشغيل الحملات المستحقة يدويًا من لوحة الإدارة. لا تُرسل الحملة المجدولة قبل وقتها، وتسجل قاعدة البيانات وقت التسليم حتى لا تُرسل مرتين.

## بناء تطبيق Expo للإنتاج

بعد إنشاء مشروع EAS ووضع معرّفه الحقيقي، نفّذ الفحوصات ثم صدّر أو ابنِ المنصات المطلوبة. استخدم دائمًا رابط خادم HTTPS فعليًا.

```bash
cd mobile
npm run doctor
npm run typecheck
npm run lint

EXPO_PUBLIC_API_URL=https://your-service.up.railway.app \
EXPO_PUBLIC_EAS_PROJECT_ID=your-real-eas-project-id \
npx expo export --platform web --output-dir dist-web --clear
```

يمكن التحقق من Android وiOS كلٌ على حدة باستخدام `--platform android` و`--platform ios`. أما ملفات المتاجر النهائية فتُبنى عبر EAS وفق حساب المشروع وشهادات التوقيع.

## التحقق قبل النشر

```bash
cd backend
npm ci
npm test
npm run lint
npx tsc --noEmit
npm run build
npm audit --omit=dev

cd ../mobile
npm ci
npm run doctor
npm run typecheck
npm run lint
npm audit --omit=dev
```

في آخر تحقق محلي اجتازت اختبارات الخادم **39/39**، وفحص Expo **21/21**، وتدقيق اعتماديات الإنتاج بلا ثغرات معروفة وقت الفحص. نجح تصدير الويب وAndroid وiOS كلًا على حدة. لا يُغني ذلك عن اختبار Tap Sandbox واختبار حمل واختبار اختراق مستقل قبل فتح التسجيل العام.
